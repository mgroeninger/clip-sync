[../](../) (`gap-fingerprint.md`, `gap-vocabulary.md`, `repair-perf.md`, `test-tiers.md`, etc.)
and the code. Links and `file:line` claims inside archive files may be stale.

Active drafts stay in [../](../) (`TEMP-*.md`); this folder is for shipped / closed / superseded
work only.

**Archiving a plan is step 1 of 3.** Step 2 is a row in [../settled.md](../settled.md) — the verdict
and the guard, one line. Step 3 is **deleting the corresponding text from
[BACKLOG.md](../../../BACKLOG.md)**. Skipping step 3 is what turned the backlog into an index of dead
ideas; the entries below are rich precisely so that `settled.md` can stay terse and point here.
