# Residual / floor gate — findings ledger

Bugs, gaps, regressions, and smells found while building the residual/floor work (P0 prototype → P1
plumbing → H1/M1 refactor → H2 experiment). Companion to
[residual-gate-wiring-plan.md](residual-gate-wiring-plan.md). Status as of the H2 experiment.

Legend: **status** = fixed / open / deferred; **sev** = high / med / low / gap / regression.

---

## Fixed (verified)

| id | sev | what | fix / evidence |
|----|-----|------|----------------|
| **H1** | high | **Reference asymmetry.** Seam residual used the standoff-/low-energy-*trimmed* border template while the floor used *raw* A windows → at any non-sample-accurate placement the trimmed template was offset by the standoff (≫ ±64 lag) → seam read ~0 cancellation while floor cancelled → spurious ~45 dB headroom at a correct same-master fill. | `seam_chosen_and_floor` measures chosen + floor on the **same raw window**; oracle headroom 44.7 → **0.0**; unit tests `seam_chosen_and_floor_*`. |
| **M1** | med | **Lag radii not unified** (seam ±64 vs floor ±512) → a true fill offset 64–512 frames showed a ~40 dB false-reject band. | Unified lag (single `max_lag_frames` from `residual_lag_secs`, both seam + floor). Placement-offset sweep @16k under the **10 ms default** (reach ≈160 frames): headroom **0.0 through offset 100, ~38 dB at ≥200** (was 34–41 across 100–512 with the old ±64 seam). No seam↔floor mismatch band. **Note:** reach now = configured lag, so a correct fill offset beyond it false-rejects (intended; tunable via `residual_lag_secs`, smaller at low sample rates). |
| **A1** | low | **Low-energy-prefix head-shift artifact**: trimmed `a_post` was offset a few dozen samples → spurious post-side headroom at the *true* fill (F1 92.3, F2 96.7). | Subsumed by H1 raw-window fix; both now **0.0**. |
| **A2** | low | Clippy: `map_or(true, …)` → `is_none_or`; `let…else { return None }` → `?`; loop index → `iter().enumerate()`. | Applied; clippy clean all-targets. |

## Open — medium

| id | sev | what | notes |
|----|-----|------|-------|
| **M2** | med | **`FLOOR_OK` uncalibrated on real codecs.** Synthetic floor (~−44 dB) is optimistic; real lossy codecs sit higher. The `informative` gate threshold is a guess until measured. | **Calibrated** (`source_gap_oracle_floor_csv`, CC speech/ambient + the Grieg/Musopen **music** master, via ffmpeg): **`FLOOR_OK = −15` validated for AAC and Vorbis across content, incl. music** (the use case). Key result — **low-bitrate floor is content-dependent**: AAC 64k is *uninformative* on speech (post **−10.2**) but *informative* on music (**−31.0**); AAC 128k informative everywhere (−20 to −44); Vorbis 128k informative (−19.7 to −31.1). **Vorbis dual** (128k/192k speech/ambient, 128k/64k music): informative with realistic independent-encode floors (≈ −20 to −25 dB), not same-bitrate −120 artifacts. `two_mic` uninformative → regime gate holds on real media. **Opus excluded** (no Symphonia Opus decoder; replaced by Vorbis). **MP3 contributes no FLOOR_OK datum** → **M4**. **Caveats:** same-bitrate Vorbis same-master can still be deterministic (−120); use **dual** rows for independent-encode floors; post-side floor inflated by gap-inject MDCT spread on AAC (conservative for `FLOOR_OK = −15`). **Remaining:** punch-after-encode oracle (M4); per-channel/5.1 (L2). |
| **M3** | med | **`seam_floor_probe` refactor edge case.** `select_reference_window` (energy gate only) + `measure_window_at_delta` no longer *walks past* a window whose B mapping is out of bounds — it returns `NaN` at the first energetic window instead. Old code walked on. | Our fixtures never hit it, but near haystack-coverage edges the new code may abstain where the old found a usable window. ## Regressions

**None found** with explicit `--residual-gate off`. Default is now **`veto`** (P4). With `residual_gate = off` / `measure_residual = false`, the verdict is not computed and `GapPatchOutcome.residual` is `None` (serde-skipped).

## Findings that aren't defects (worth keeping)

- **Residual is a better gate signal than Pearson for broadband.** At a correct same-master placement, residual headroom = 0 while Pearson ≈ 0 — so residual *rescues* fills Pearson falsely skips, not only *vetoes* echoes. This is the empirical motivation for the rescue path (H2-B fix).
- **The floor-informative check is the same-master regime gate for free** — two-mic pairs can't cancel → floor uninformative → gate abstains, so `donor_relation` is derived, not an input.
- **Nominal-floor headroom is not an F4 echo detector.** When structure lands on the nominal (decoy) placement, chosen and floor share the same offset → headroom ≈ 0 even when the fill is editorially wrong (**M6**). Truth-anchored disagreement rows measure whether veto *would* fire given oracle geometry; full-pipeline F4 is handled by signature mode, not residual veto.
- **Harness ↔ pipeline representativeness restored.** The direct harness was updated to the unified `seam_chosen_and_floor` model so its numbers predict pipeline behavior (the old ±64/±512 false-reject band was a harness artifact, now gone).

## Validation infrastructure (where the evidence lives)

- **`tests/seam_residual_corpus.rs`** — direct-scoring harness (truth/decoy CSV, broadband CSV, placement-offset sweep).
- **`tests/seam_residual_oracle.rs`** — in-memory same-master oracle through `PatchAudio` (`seam_residual_oracle_csv`; H2-B rescue test `broadband_oracle_veto_rescue_patches_marginal`; `seam_residual_h2_placement_experiment`).
- **`tests/floor_oracle_integration.rs`** + floor-oracle manifest — real-codec FLOOR_OK calibration (`source_gap_oracle_floor_csv`, CC **speech/ambient/music** masters via ffmpeg; G3). Validated codecs: **AAC, Vorbis, WAV**; **Vorbis dual** (independent-encode floors); **MP3 excluded** (**M4**). Also: **real-codec gate** (`floor_oracle_residual_gate_real_codec`); **`veto_rescue` on real broadband/dual Vorbis** (`floor_oracle_veto_rescue_real_broadband_codec` — rescue matches veto on truth; synthetic H2-B dead-zone rescue: `broadband_oracle_veto_rescue_patches_marginal`).
- **Disagreement table** — `seam_residual_disagreement_csv` (`#[ignore]`, ~96 s): one row per (fixture, variant, placement) over F1/F2/F4 @ {truth, decoy, nominal} + broadband @ {clean, codec_noise}, columns `oracle_correct, pearson_min, pearson_tier, pearson_patches, informative, headroom_db, veto_outcome, rescue_outcome, veto_flipped, rescue_flipped`. CI-fast asserts in `seam_residual_disagreement_oracles` (~23 s): **F4 decoy → Pearson passes, veto flips** (truth-anchored floor); **F1 truth → veto agrees (no flip)**; **broadband codec-noise truth → Pearson dead zone, rescue flips**. Pipeline F4 bool+veto: `f4_decoy_residual_gate_vetoes_bool` (ignored) — bool patches decoy (nominal headroom ≈ 0); energy patches truth (**M6**). **M5:** `floor_oracle_vorbis_64k_veto_no_false_veto` (ignored, real codec). **Caveat:** disagreement cells use a **true-anchored** floor when nominal ≠ truth (F4/F2); reach abstention is disabled in the harness when the floor anchor ≠ nominal. Production uses **nominal** floor anchor throughout.
